# Diccionario de datos

## `ventas.csv` (sintético)
| Campo | Tipo | Descripción |
|---|---|---|
| id | entero | Identificador. |
| region | texto | Norte / Sur / Este. |
| producto | texto | A / B. |
| unidades | entero | Unidades vendidas. |
| precio | decimal | Precio unitario. |

## `ventas_powerbi.csv` (sintético)
Como `ventas.csv` + `fecha` (AAAA-MM-DD) para inteligencia de tiempo y KPIs mensuales.

## `iris_sintetico.csv` (sintético)
| Campo | Descripción |
|---|---|
| largo_sepalo_cm | Largo del sépalo (valores inventados). |
| ancho_sepalo_cm | Ancho del sépalo. |
| clase | 0, 1, 2 (etiqueta inventada). |

> Todos los datasets son sintéticos, sin datos personales. Licencia: uso libre de práctica interno.
