# Mapa curricular (ver `data/curriculum.json` y `docs/phase0/map.md`)
Mundos 0–10 definidos en `data/curriculum.json`. Cada lección sigue la estructura obligatoria de 20 campos.
- Mundo 0: contenido real completo (8 lecciones + proyecto ventas).
- Mundo 1 (Excel): intro real (3 lecciones + laboratorio hojas con fórmulas documentadas) + roadmap resto.
- Mundo 3 (SQL): intro real (4 lecciones + 4 ejercicios SQL verificables).
- Mundo 4 (Python): intro real (4 lecciones + 4 ejercicios ejecutables).
- Mundos 2,5–10: estructura temática + competencias + borradores marcados `status: planned` (no se presentan como terminados).
Competencia = observable + criterio de dominio (>=80% en evaluación + práctica lograda).
