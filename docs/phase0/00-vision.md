# Visión — DataQuest Academy
- Plataforma autoaprendizaje en español, de cero a preparación para Ciencia de Datos.
- Enseña haciendo: lecciones progresivas, laboratorios reales (SQL/Python ejecutables), retos, proyectos y evaluación verificable.
- Principios: evidencia de aprendizaje (no basta leer), retroalimentación inmediata, competencias medibles, sin botones falsos, seguridad y accesibilidad.
- MVP vertical: Mundo 0 completo + introducción Excel/SQL/Python + 1 proyecto integrador. Mundos 1–10 planificados y estructurados por fases 9–10.
