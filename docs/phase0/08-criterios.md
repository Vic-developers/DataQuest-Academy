# Criterios de aceptación (MVP)
- Registro/login, dashboard, mapa y progreso reales contra API.
- Lecciones Mundo 0 completables con XP y desbloqueo validado.
- Ejercicios SQL/Python ejecutados y corregidos con tests/resultados reales.
- Proyecto integrador con entrega y rúbrica.
- Certificado verificable por código.
- Tests backend pasan; frontend compila; auditoría de XP idempotente.
- Documentación install/operate, README + CHANGELOG.
