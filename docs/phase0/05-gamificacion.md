# Gamificación
XP: lección 10, ejercicio 20, evaluación 50, misión 100, proyecto 300, desafío final 500. Idempotente: una sola vez por actividad (anti-farm).
Niveles: 10 rangos desde Explorador de Datos hasta Explorador de Ciencia de Datos (umbrales en `services/gamification.py`, rangos internos, no certificación profesional).
Mapa visual SVG con nodos Mundo→lección, estado (bloqueado/desbloqueado/completado), rutas de refuerzo.
Rachas: un evento de aprendizaje por día, recuperación limitada 1/semana, días de descanso configurables, sin castigos excesivos.
Moneda: solo cosmética (avatar/tema); nunca compra aprobación/certificados.
Rankings: opt-in, semanales por XP real, sin datos personales públicos.
